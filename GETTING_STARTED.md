# Getting Started with USB Camera Viewer

Welcome! This guide will help you get started quickly.

## 🚀 Quick Install

```bash
# Install the app
adb install app/build/outputs/apk/release/app-release-unsigned.apk
```

## 📱 First Use

1. **Open** the app
2. **Grant** camera permission
3. **Connect** USB camera
4. **Grant** USB permission
5. **Done!** Camera view appears

## ✨ Key Features

- Full-screen camera display
- Multiple resolutions (4K to VGA)
- Frame rate control (60 to 15 FPS)
- Image rotation and flip
- Settings persistence
- Auto-launch on camera attach
- Camera controls (brightness, contrast, etc.)

## 🎯 Common Tasks

### Change Resolution
1. Tap ⚙ icon
2. Select "Resolution"
3. Choose desired resolution

### Rotate Image
1. Tap ⚙ icon
2. Select "Rotation"
3. Choose angle

### Adjust Brightness
1. Tap ⚙ icon
2. Tap "Camera Controls"
3. Adjust brightness slider
