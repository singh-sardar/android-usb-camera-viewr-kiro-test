USB CAMERA VIEWER - PROJECT SUMMARY
====================================

VERSION: 1.2
DATE: November 2024
STATUS: Production Ready

OVERVIEW
--------
Clean, efficient Android app for viewing USB cameras with real-time controls.
Uses AndroidUSBCamera (AUSBC) library with native libuvc support.

KEY METRICS
-----------
APK Size: 8.6 MB
Code Files: 4 Kotlin files
Total Lines: ~590 lines
Dependencies: Minimal (AUSBC + AndroidX)
Min SDK: 21 (Android 5.0)
Target SDK: 33 (Android 13)

FEATURES
--------
✅ Live USB camera preview
✅ Multiple resolutions (640x480 to 4K)
✅ FPS control (15-60 fps)
✅ Image rotation (0°, 90°, 180°, 270°)
✅ Flip controls (H/V)
✅ Camera adjustments (brightness, contrast, saturation)
✅ Auto best configuration
✅ Settings persistence
✅ Auto-launch on USB connect
✅ In-app log viewer
